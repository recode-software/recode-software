The website for the Warsaw-based "Polityka Dla Miast" program consists of a static page with news updates and
a program description. In addition to the static content, a dynamic system similar to Wikipedia with a custom editor
has been programmed. Furthermore, an administrative panel has been developed to manage articles contributed
by academic circles and regular users.
