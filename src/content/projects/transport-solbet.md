The system created for Solbet was built from scratch to make it easy to issue orders to employees.
Dispatchers have the ability to log into the system and carry out courses added to the platform.
The system uses elements such as OCR to read transport documents, an automated system for issuing entry documents,
and auction-type orders that are updated periodically.
The system utilizes websockets, enabling asynchronous communication.
